# RAG-Lernsystem Android (Lite)

Abgespeckte, komplett lokale Android-Version des RAG-Lernsystems: Chat mit Quellen (RAG), Karteikarten mit FSRS, Zusammenfassungen und Pomodoro. Die KI (Gemma 4) läuft auf dem Gerät und wird beim ersten Start nachgeladen.

Status: Planungsphase. Siehe [docs/PLAN.md](docs/PLAN.md).

Persönliche Unterlagen und Eval-Daten gehören nach `eval/private/` (nicht versioniert).
